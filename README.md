Jatre-Namma Pride is an Android application developed as part of the MindMatrix VTU Internship Program to digitally manage and organize village fairs (Jatre) using modern technology. The main objective of the project is to help visitors and local communities access live event schedules, safety information, parking details, cultural stories, and lost & found services through a single mobile application. In many rural festivals, visitors often face problems such as lack of event information, difficulty finding parking or first-aid centers, and confusion during large gatherings, so this application provides a smart digital solution using Android Studio, Firebase, Google Maps API, and Material Design. The app includes features like live schedule updates for events such as Rathotsava, wrestling, and drama shows, a lost & found module where users can upload photos and details of lost items or missing persons, parking and emergency location guidance through maps integration, and cultural stories explaining the history and traditions of the Jatre. Firebase Authentication is used for secure login and registration, Firestore is used for real-time database management, and Firebase Storage is used for image uploads. The project improves public safety, crowd management, communication, and cultural awareness while supporting rural digital transformation. Future enhancements may include AI chatbot support, Kannada voice assistant, SOS emergency services, live crowd tracking, push notifications, and offline map support. Overall, Jatre-Namma Pride demonstrates how technology can modernize traditional festivals and create a safe, organized, and user-friendly digital experience for large cultural gatherings.
